# 配置 ORM

### 启动电脑mysql 
```
net start MySQL80
```
### 启动项目
```
uvicorn main:app

py main.py
```

### 查看接口
 - http://127.0.0.1:10001/docs


### 安装
- pip install -r requirements.txt 按照依赖文件文本安装依赖
- pip install sqlalchemy asyncio pymysql aiomysql
- sqlalchemy 用于数据库操作
- asyncio 用于异步操作
- pymysql 用于 MySQL 数据库
- aiomysql 用于异步 MySQL 数据库

### 建表
- 1. create_async_engine 创建异步引擎
- 2. 定义模型基类（继承 DeclarativeBase）和 模型类
- 3. run_sync(Base.metadata.create_all) 建表

### 操作数据
- 1. 路由处理函数注入数据库会话依赖项 Depends
- 2. 查询数据:select()
- 3. 增加数据:add()
- 4. 更新数据:重新赋值
- 5. 删除数据:delete()
