# 头条 App 前端项目设计规划

> 基于 Vue3 技术栈开发的简易版头条应用

---

## 一、核心技术栈要求

| 技术类别 | 技术选型 | 说明 |
|---------|---------|------|
| 框架 | Vue 3 | Composition API + `<script setup>` 语法 |
| 构建工具 | Vite | 快速开发与构建 |
| 状态管理 | Pinia | 全局状态管理 |
| 路由 | Vue Router 4 | 页面路由与导航 |
| 网络请求 | Axios | 封装请求/响应拦截器 |
| UI 组件库 | Element Plus | 移动端适配优先 |
| 样式 | CSS/SCSS | 支持 rem/vw/vh 移动端适配 |

---

## 二、核心功能模块

### 1. 首页模块

**页面结构：**
- 顶部：新闻分类导航栏（对接 `/api/news/categories` 接口）
- 主体：新闻列表展示（支持分页，对接 `/api/news/list` 接口，可按分类筛选）

**功能要点：**
- 点击新闻条目进入详情页（对接 `/api/news/detail` 接口）
- 自动添加浏览记录（对接 `/api/history/add` 接口）
- 新闻详情页展示浏览量
- 返回按钮

---

### 2. AI 问答模块

**页面结构：**
- 输入框（支持多行输入）
- 发送按钮
- 问答记录列表

**功能要点：**
- 模拟 AI 问答交互（前端模拟返回固定回答，无需真实 AI 接口）
- 对话气泡式展示，区分用户提问 / AI 回答

---

### 3. 我的模块

**用户信息：**
- 用户信息展示（对接 `/api/user/info` 接口，需 Token 认证）

**收藏管理：**
| 操作 | 接口 |
|-----|------|
| 展示收藏列表 | `/api/favorite/list` |
| 取消收藏 | `/api/favorite/remove` |
| 清空收藏 | `/api/favorite/clear` |
| 检查收藏状态 | `/api/favorite/check` |

**历史管理：**
| 操作 | 接口 |
|-----|------|
| 展示浏览历史 | `/api/history/list` |
| 删除单条历史 | `/api/history/delete/{history_id}` |
| 清空历史 | `/api/history/clear` |

**个人设置：**
| 操作 | 接口 |
|-----|------|
| 修改用户信息 | `/api/user/update` |
| 修改密码 | `/api/user/password` |

**基础功能：**
- 登录 / 注册入口（对接 `/api/user/register`、`/api/user/login`）
- 退出登录

---

## 三、对接后端规范

### 1. 认证机制

- 登录成功后存储 Token 到 `localStorage`
- 请求头自动携带 `Authorization: token` 值
- Token 有效期 7 天，过期后自动跳转登录页

### 2. 错误处理

- 统一捕获异常状态码：
  - `401`：认证失败
  - `404`：资源不存在
  - `500`：服务器错误
- 弹窗提示用户
- 所有接口返回统一 JSON 格式解析

### 3. 缓存逻辑

- 前端无需重复缓存（依赖后端 Redis 缓存）
- 仅做接口数据暂存

## 四、代码规范要求

### 1. 目录结构

```
src/
├── api/              # 接口封装（按模块拆分：user.js、news.js、favorite.js、history.js）
├── assets/           # 静态资源（图片、样式）
├── components/       # 公共组件（如 NewsItem.vue、CategoryNav.vue）
├── layouts/          # 布局组件（如 MainLayout.vue）
├── pages/            # 页面组件（Home.vue、AiChat.vue、Mine.vue）
├── pinia/            # Pinia 状态管理（userStore.js、newsStore.js 等）
├── router/           # 路由配置（index.js）
├── utils/            # 工具函数
│   ├── request.js    # Axios 封装
│   └── auth.js       # Token 管理
├── App.vue
└── main.js
```

### 2. 编码规范

**组件命名：**
- 大驼峰命名（如 `NewsDetail.vue`）
- 公共组件前缀为 `Base`（如 `BaseButton.vue`）

**接口封装：**
- 每个模块的接口单独封装
- 函数名语义化（如 `getNewsList`、`addFavorite`）

**注释规范：**
- 关键逻辑添加注释
- 接口函数说明入参 / 出参 / 用途

**异步操作：**
- 使用 `async/await`
- 统一处理异常
